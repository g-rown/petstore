## Summary

Build a full-stack pet e-commerce application with a Spring Boot 3 REST API backend (PostgreSQL, JWT auth, Flyway migrations) and a React frontend (Vite, Tailwind CSS v3, MUI v5). The app enables browsing a categorized pet catalog (Dogs, Cats, Birds, Fish), user registration/authentication, server-side shopping cart, checkout with order placement, order history, and admin pet management. All API endpoints are served under `/gulles/v1/`. Deployment targets Render (Web Service + Static Site + Managed PostgreSQL).

## Technical Context

**Language/Version**: Java 17+ (backend), JavaScript/ES2022 (frontend)
**Primary Dependencies**: Spring Boot 3.x, Spring Data JPA, Spring Security, React 18, Vite, Tailwind CSS v3, MUI v5, Axios, React Router v6
**Storage**: PostgreSQL 15+ via Render Managed PostgreSQL
**Testing**: JUnit 5 + Spring Boot Test (backend), manual browser verification (frontend)
**Target Platform**: Web (all modern browsers)
**Project Type**: Web application (backend API + frontend SPA)
**Constraints**: Render free/starter tier; no payment processing; pet images via external URLs

## Proposed Changes

### Backend — Project Setup & Configuration

#### [NEW] pom.xml
Maven project descriptor with Spring Boot 3.x parent, dependencies: spring-boot-starter-web, spring-boot-starter-data-jpa, spring-boot-starter-security, spring-boot-starter-validation, postgresql driver, flyway-core, jjwt (0.12.x), springdoc-openapi, lombok.

#### [NEW] PetStoreApplication.java
Standard Spring Boot main class with `@SpringBootApplication`.

#### [NEW] application.yml / application-dev.yml / application-prod.yml
Base config with server port (8080), context-path (`/gulles`), JPA settings. Dev profile uses local PostgreSQL. Prod profile reads `DATABASE_URL` from env.

#### [NEW] SecurityConfig.java
Spring Security config: stateless sessions, JWT filter chain, public endpoints (`/gulles/v1/auth/**`, `/gulles/v1/pets/**`, `/gulles/v1/categories/**`, `/gulles/v1/health`), role-based access for admin endpoints.

#### [NEW] CorsConfig.java
CORS configuration allowing frontend origin (configurable via env var).

#### [NEW] JwtUtil.java + JwtAuthenticationFilter.java
JWT token generation/validation utility. OncePerRequestFilter that extracts and validates JWT from Authorization header.

---

### Backend — Data Model & Migrations

#### [NEW] Flyway Migrations (V1–V6)
- V1: `categories` table (id, name, display_name, description, image_url)
- V2: `pets` table (id, name, breed, age_months, price, description, image_url, status, category_id FK, created_at, version for optimistic locking)
- V3: `users` table (id, email UNIQUE, password_hash, first_name, last_name, role, created_at)
- V4: `cart_items` table (id, user_id FK, pet_id FK, UNIQUE(user_id, pet_id), created_at)
- V5: `orders` + `order_items` tables
- V6: Seed 4 categories + 24 sample pets (6 per category) + 1 admin user

#### [NEW] JPA Entities (Category, Pet, User, CartItem, Order, OrderItem)
Standard JPA entities with proper annotations. Pet has `@Version` for optimistic locking. Enums: PetStatus, UserRole, OrderStatus.

#### [NEW] Spring Data Repositories
JpaRepository interfaces with custom query methods (e.g., `findByCategoryAndStatus`, `findByUserAndPet`).

---

### Backend — Service Layer

#### [NEW] AuthService.java
Register (BCrypt hash, save, generate JWT), login (authenticate, generate JWT).

#### [NEW] PetService.java
Find all with filtering (category, status=AVAILABLE) + pagination + sorting. Find by ID. Create/update/delete (admin).

#### [NEW] CartService.java
Get cart items for user. Add pet to cart (check availability, check uniqueness). Remove item. Clear cart.

#### [NEW] OrderService.java
Place order: validate all cart pets are AVAILABLE (within a `@Transactional`), create Order + OrderItems, snapshot prices, update pet status to SOLD, clear cart. Get orders for user. Get order by ID.

---

### Backend — Controllers & DTOs

#### [NEW] Controllers (Auth, Pet, Category, Cart, Order, Health)
REST controllers mapped under `/v1/` (combined with context-path `/gulles` → `/gulles/v1/`). All return `ApiResponse<T>` envelope. Health controller returns simple status.

#### [NEW] DTOs
Request DTOs with Jakarta validation annotations. Response DTOs mapping entities to API contracts. `ApiResponse<T>` wrapper with success, data, message, timestamp.

#### [NEW] GlobalExceptionHandler.java
`@RestControllerAdvice` handling: ResourceNotFoundException (404), PetUnavailableException (409), MethodArgumentNotValidException (400), generic Exception (500). All return error envelope.

### Frontend — Core Infrastructure

#### [NEW] axiosInstance.js
Axios instance with `VITE_API_BASE_URL` base URL, JWT interceptor (attach token from localStorage), 401 response interceptor (clear token, redirect to login).

#### [NEW] AuthContext.jsx + useAuth.js
Context provider: user state, login/logout/register functions, token management, initialization from localStorage on mount.

#### [NEW] CartContext.jsx + useCart.js
Context provider: cart items state, item count, addToCart/removeFromCart/clearCart functions, fetch cart on auth change.

#### [NEW] App.jsx
React Router setup with all routes. ProtectedRoute wrapper for authenticated pages. AdminRoute wrapper for admin pages. AuthContext + CartContext providers.

#### [NEW] CatalogPage.jsx (US1)
Pet grid with category filter (from URL param), sort dropdown (price asc/desc, name), MUI Pagination component. Uses PetCard and PetGrid components.

#### [NEW] PetDetailPage.jsx (US1)
Large pet image, full details (name, breed, age, price, description, status). "Add to Cart" button (disabled if not authenticated or pet unavailable). Back to catalog link.

MUI form components with validation. Error display. Redirect after success.

#### [NEW] CartPage.jsx (US3)
List of cart items with image, name, breed, price, remove button. Subtotal calculation. "Proceed to Checkout" button. Empty state with CTA.

#### [NEW] CheckoutPage.jsx + OrderConfirmationPage.jsx (US4)
Order summary review. "Place Order" button. Confirmation with order number and details.

#### [NEW] OrderHistoryPage.jsx (US5)
Accordion/expandable list of past orders with details. Empty state.

#### [NEW] AdminPage.jsx (US6)
MUI DataGrid/Table with all pets. Add/Edit dialog form. Delete confirmation. Role-guarded route.
